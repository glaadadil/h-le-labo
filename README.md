# H le Labo

Laboratoire pédagogique interactif : observer, déduire, comprendre et appliquer.

**Ouvrir : https://glaadadil.github.io/h-le-labo/**

- L’accueil ouvre le catalogue des ateliers.
- Le circuit électrique de référence reste accessible dans `lab3d/`.
- `classique.html` conserve la version 2D de secours.
- Les carnets et les essais sont enregistrés dans le navigateur utilisé. Ils ne sont pas synchronisés entre appareils, navigateurs ou adresses de site.

Ce site utilise HTML, CSS, JavaScript et Three.js, sans serveur applicatif ni base de données. Les modèles, pages de référence et limites sont indiqués dans Aide et Mesures.

Publication GitHub Pages depuis la racine de la branche `main`. Le fichier `.nojekyll` permet de servir directement les fichiers.

Le code de Three.js conserve sa licence dans `lab3d/vendor/THREE-LICENSE.txt`.
